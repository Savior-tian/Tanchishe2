## 功能介绍

| 功能 | 说明 |
|------|------|
| 用户注册 | 首次使用时注册账号，密码隐式输入（显示`*`） |
| 用户登录 | 登录验证，最多允许 3 次失败 |
| 贪吃蛇游戏 | 键盘方向键控制，F1 加速、F2 减速，Space 暂停 |
| 得分系统 | 吃到食物自动加分，加速状态得分更高 |
| 游戏日志 | 每局自动记录用户、开始时间、时长、得分，支持随时查看 |
| 再来一把 | 游戏结束后可选择重开，无需重新登录 |

## 数据结构定义

### 用户表

存储文件：`users.dat`（文本格式，每行一条记录）

| 字段名 | 类型 | 长度 | 说明 |
|--------|------|------|------|
| `id` | int | 4 | 用户唯一标识，自增 |
| `username` | char | 32 | 用户名，注册时唯一 |
| `password` | char | 32 | 密码（明文存储） |

**存储格式示例：**
```
1 alice password123
2 bob mypassword
```

### 游戏日志表

存储文件：`gamelog.dat`（文本格式，`|` 分隔，每行一条记录）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `userID` | int | 对应用户表的 id |
| `username` | char[32] | 用户名 |
| `startTime` | char[20] | 游戏开始时间，格式 `YYYY-MM-DD HH:MM:SS` |
| `duration` | char[8] | 游戏时长，格式 `MM:SS` |
| `score` | int | 本局最终得分 |

**存储格式示例：**
```
1|alice|2025-04-24 10:30:00|02:15|180
2|bob|2025-04-24 11:00:00|00:47|50
```

## 算法流程图

### 主程序流程

```mermaid
flowchart TD
    A([程序启动]) --> B[设置控制台UTF-8编码]
    B --> C[显示主菜单]
    C --> D{用户选择}
    D -- 1.注册 --> E[用户注册流程]
    D -- 2.登录 --> F[用户登录流程]
    D -- 3.进入游戏 --> G{是否已登录?}
    D -- 4.查看日志 --> H[显示游戏日志]
    D -- 5.退出 --> Z([程序结束])
    G -- 否 --> C
    G -- 是 --> I[游戏初始化 gamestart]
    E --> C
    F --> C
    H --> C
    I --> J[游戏循环 gamecircle]
    J --> K{游戏结束?}
    K -- 否 --> J
    K -- 是 --> L[显示结束菜单 endgame]
    L --> M{玩家选择}
    M -- 再来一把 --> I
    M -- 查看日志 --> H2[显示游戏日志]
    H2 --> L
    M -- 回主界面 --> C
```

### 蛇体移动算法流程

```mermaid
flowchart TD
    A([snakemove 调用]) --> B[cantcrosswall: 检测当前头部是否撞墙]
    B --> C{撞墙?}
    C -- 是 --> D[endgamestatus=1, 调用endgame]
    C -- 否 --> E[根据status计算方向向量 dx,dy]
    E --> F[计算 nexthead 坐标\nnexthead.x = head.x + dx\nnexthead.y = head.y + dy]
    F --> G{nexthead == food 位置?}
    G -- 是,吃到食物 --> H[nexthead加入链表头部]
    H --> I[重绘整条蛇体]
    I --> J[score += add]
    J --> K[createfood: 生成新食物]
    G -- 否,正常移动 --> L[nexthead加入链表头部]
    L --> M[绘制蛇头到倒数第二节]
    M --> N[擦除原尾节点]
    N --> O[释放尾节点内存]
    K --> P[biteself: 检测是否咬到自身]
    O --> P
    P --> Q{咬到自身?}
    Q -- 是 --> R[endgamestatus=2, 调用endgame]
    Q -- 否 --> S([返回])
    D --> S
    R --> S
```

## 用户界面说明

| 颜色 | 用途 |
|------|------|
| 黄色 (14) | 标题栏、边框、得分高亮 |
| 绿色 (10) | 蛇体、已登录用户名 |
| 红色 (12) | 食物（★）、失败提示 |
| 青色 (11) | 得分面板、输入提示 |
| 灰色 (8) | 未登录状态提示 |

游戏中光标自动隐藏（`HideCursor`），返回主菜单后恢复（`ShowCursor`）。

## 操作说明

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 控制蛇的移动方向 |
| `F1` | 加速（加分倍率提高） |
| `F2` | 减速（加分倍率降低） |
| `Space` | 暂停 / 继续 |
| `F5` | 游戏中查看历史日志 |
| `ESC` | 退出当前局 |
